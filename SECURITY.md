# Security policy

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository.
Do not open public issues for security problems. You will get a reply within 7 days.

Scope: the PHP application in `app/`, the formula engine, and the admin panel. Out of scope: the third-party libraries in
`app/public/assets/vendor/` (report upstream) and denial-of-service through volume.
