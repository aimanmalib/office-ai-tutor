# Gaya tulisan — semua teks pengguna (BM + EN)

Terpakai pada setiap teks yang pelajar baca: halaman, cheat sheet, rujukan, latihan, mesej UI, arahan AI tutor.
Sasaran: bunyi seperti buku teks yang baik atau dokumentasi produk yang serius, bukan iklan dan bukan chatbot.

## Prinsip

1. **Khusus, bukan bersemangat.** Sebut apa benda itu buat, dengan contoh atau angka. "Jumlahkan nombor dalam julat"
   bukan "Kira dengan mudah dan pantas!".
2. **Satu ayat, satu idea.** Ayat pendek. Tiada rantai sengkang (—) untuk menyambung tiga idea.
3. **Tiada tanda seru** dalam teks halaman. Tiada soalan retorik ("Pernah tertanya-tanya…?").
4. **Tiada emoji** dalam teks. Ikon dikawal oleh reka bentuk (medan `ikon` = nama ikon Lucide, lihat bawah).
5. **Jangan puji diri sendiri.** Tiada "terbaik", "paling lengkap", "revolusi", "power", "best", "magic", "rahsia".
6. **Sebut had dengan jujur.** "AI boleh tersilap. Uji formula dalam Excel sendiri." — sekali, di tempat yang betul.
7. Tajuk = huruf besar ayat sahaja (sentence case): "Rujukan fungsi", "Function reference". Bukan Title Case Semua.

## Perkataan dilarang

- **EN:** unlock, supercharge, seamless(ly), elevate, empower, journey, dive in/deep dive, game-changer, effortless(ly),
  revolutionize, harness, leverage (kata kerja), unleash, master (kata kerja dalam tajuk), "in today's world",
  "whether you're … or …", "look no further", "take … to the next level", magic, ultimate, powerful (sebagai pujian),
  "made easy", "at your fingertips", "boost", "next-level", "robust", "cutting-edge".
- **BM:** jom, best, power, magic, rahsia, "jadi senang", "tak perlu Google lagi", "di hujung jari", "secara pintar",
  revolusi, "tahap seterusnya", "wajib hafal", "paling lengkap", "cincai", "gempak", "terbaik".
- **BM bahasa pasar** (dalam teks rasmi): tak→tidak, nak→hendak/mahu, kalau→jika/apabila, pasal→tentang,
  macam mana→bagaimana, dah→sudah, je→sahaja, buat→membuat (bila kata kerja), "dari" untuk sumber orang/benda→"daripada",
  "guna"→"gunakan"/"menggunakan" bila ayat penuh. Bahasa Melayu Malaysia (DBP), BUKAN Indonesia
  (Isi Kandungan, bukan Daftar Isi; fail, bukan berkas; tetikus, bukan mouse dalam ayat BM; padam, bukan hapus).

## Istilah (BM)

Nama menu, tab, butang, fungsi dan ralat kekal **tepat seperti dalam aplikasi berbahasa Inggeris** (Home → Conditional
Formatting, `VLOOKUP`, `#N/A`, Page Break, Slide Master). Konsep am dalam ayat BM menggunakan istilah ini, secara konsisten:

| EN | BM | | EN | BM |
|---|---|---|---|---|
| cell | sel | | worksheet / sheet | lembaran kerja / sheet |
| row | baris | | workbook | buku kerja (fail Excel) |
| column | lajur | | range | julat |
| formula | formula | | function | fungsi |
| argument | argumen | | value | nilai |
| text | teks | | date | tarikh |
| chart | carta | | table | jadual |
| shortcut | pintasan | | slide | slaid |
| criteria | kriteria | | lookup | carian (fungsi carian) |
| total | jumlah | | average | purata |
| error | ralat | | dashboard | papan pemuka (dashboard) |

## EN

Bahasa Inggeris antarabangsa, ejaan AS (selaras dengan Microsoft: "color", "center"). Nada dokumentasi Microsoft Learn /
Stripe Docs: terus, tepat, mesra tanpa bermanja. "You" boleh; "we" jarang.

## Pintasan papan kekunci

Windows ialah rujukan. Jangan reka pintasan. Bila tidak pasti ia wujud dalam versi semasa Microsoft 365, buang item itu.
Untuk Mac: hanya bila pasti; jika tidak, jangan sebut.

## Format teks dalam data

Medan teks boleh menggunakan `<strong>`, `<code>`, `<em>` sahaja (lain dibuang semasa dipapar). Formula, nama fungsi
dan rujukan sel dalam `<code>`.
